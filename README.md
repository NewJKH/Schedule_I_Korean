# Schedule I 한글패치 (비공식)

<img width="1920" height="1080" alt="{A50707AD-12B4-482B-8CA8-96F1409AC7BA}" src="https://github.com/user-attachments/assets/3256d8d2-eb2d-4bc2-a8c3-87d871081dcb" />


[Schedule I](https://store.steampowered.com/app/3164500/Schedule_I/) 게임의 비공식 한글패치입니다.

- 번역 항목 **58,000개 이상** (대사, UI, 아이템 설명, 퀘스트, 튜토리얼 등)
- 가격·이름·장소가 실시간으로 끼어드는 문장까지 처리하는 **정규식 조립 번역**
- 일반 번역기가 놓치는 UI까지 잡아주는 **전용 보조 플러그인** (KoreanTextFixer)
- **을지로체 폰트** 적용 (선택)
- 게임 플레이 중에는 인터넷 번역 서비스를 쓰지 않음 — **번역은 완전 오프라인 작동**

## 다운로드

**[⬇ 최신 버전 다운로드 (ZIP)](https://github.com/enddl3788/Schedule_I_Korean/archive/refs/heads/main.zip)** ← 이 링크를 누르면 바로 받아집니다

깃허브가 익숙하지 않아도 괜찮습니다. 위 링크를 누르면 ZIP 파일이 바로 다운로드됩니다.
직접 찾아 받으려면 이 페이지 위쪽의 초록색 **`< > Code`** 버튼 → **`Download ZIP`** 을 누르세요.

받은 ZIP은 **압축을 풀어야** 합니다. (압축 안에서 바로 실행하면 작동하지 않습니다)
파일 우클릭 → "압축 풀기" 또는 반디집·알집 등으로 풀어주세요.

## 설치 방법 (3단계)

1. 게임을 완전히 종료합니다.
2. 압축을 푼 폴더에서 **`설치.bat` 을 더블클릭**합니다.
3. 중간에 **"한글 폰트도 적용할까요?"** 라고 물으면 그냥 **엔터**를 누르세요. 끝!

**미리 준비할 것은 없습니다.** BepInEx나 번역기를 직접 설치하지 않아도 되며, `설치.bat`이 알아서 처리합니다.

> **폰트는 왜 물어보나요?**
> 게임 기본 폰트에는 한글이 없어서, 폰트를 바꾸지 않으면 번역된 글자가 네모(ㅁ)로 깨져 보일 수 있습니다.
> 다만 이 작업은 게임 원본 파일 1개를 수정하기 때문에(원본은 자동 백업) 동의를 받고 진행합니다.
> 건너뛰었다면 나중에 `폰트적용.bat`으로 언제든 적용할 수 있습니다.

> Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.

### 첫 설치에는 인터넷이 필요합니다 (약 21MB)

아래 2개는 원 제작자의 공식 출처에서 직접 받는 것이 신뢰성·라이선스 측면에서 낫기 때문에, 패키지에 넣지 않고 설치 시 자동으로 내려받습니다. **이미 설치되어 있으면 건너뜁니다** (두 번째 실행부터는 다운로드 없음).

| 자동 다운로드 | 출처 | 크기 |
|---|---|---|
| BepInEx (IL2CPP) | builds.bepinex.dev 공식 빌드서버 | 약 20MB |
| XUnity.AutoTranslator 5.6.1 | GitHub 공식 릴리스 | 약 0.7MB |

나머지는 전부 `payload` 폴더에 **동봉되어 있어 다운로드가 필요 없습니다** — 번역 파일 4종, KoreanTextFixer 플러그인, 번역기 설정, 을지로체 폰트, 폰트 교체 도구(AssetsTools.NET·classdata.tpk).

특히 **`폰트적용.bat`은 인터넷 접속을 전혀 하지 않습니다.**

## 게임이 업데이트되면

번역이 풀리거나 폰트가 원래대로 돌아올 수 있습니다. **`설치.bat` → `폰트적용.bat`** 을 다시 실행하면 복원됩니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 설치.bat이 바로 꺼짐 | ZIP 압축을 풀지 않고 실행한 경우입니다. 압축을 풀고 다시 실행하세요 |
| 번역이 하나도 안 나옴 | `설치.bat` 재실행 후 게임 재시작 |
| 글자가 네모(ㅁ)로 깨짐 | `폰트적용.bat` 실행 |
| 일부만 영어로 나옴 | `BepInEx\Translation\ko\Text\_AutoGeneratedTranslations.txt` 삭제 후 재시작 |
| 게임이 이상해짐 | `잠금해제.bat` 실행 → Steam 게임 파일 무결성 검사 |
| 원래대로 되돌리기 | 무결성 검사 + `BepInEx` 폴더 삭제 |

## 게임 중 단축키

- `Alt + T` : 번역 켜기/끄기 (원문 확인)
- `Alt + R` : 번역 파일 다시 불러오기

## 알려진 한계

- 메인 화면의 **Community Vote 배너**는 개발사 서버에서 실시간으로 받아오는 콘텐츠라 번역되지 않습니다.
- 플레이어가 직접 지은 이름(믹스 이름 등)은 번역 대상이 아닙니다. 단, 게임이 자동 생성한 이름(예: Purple Cake)은 번역됩니다.

## 저장소 구조

```
설치.bat            ← 한글패치 설치 (더블클릭) — 폰트 적용까지 물어봄
폰트적용.bat        ← 폰트만 따로 적용하고 싶을 때
잠금해제.bat        ← 문제 시 설정 잠금 해제
install.ps1         ← 설치 스크립트 본체
font_patch.ps1      ← 폰트 패치 스크립트 본체
payload/            ← 번역 파일, 설정, 폰트, 플러그인
src/KoreanTextFixer ← 보조 플러그인 C# 소스
FONT_LICENSE.md     ← 폰트 라이선스 고지
```
